[08] OBS Studio & Streamlabs Integration Guide
1
Under the Sources dock in OBS Studio, click the + (Add) button and select Browser.
2
Select Create new, name the source Stream Chat HUD, ensure Make source visible is checked, and click OK.
3
In the Browser Source Properties dialog, configure the fields according to the specification table below.
OBS Property Field Recommended Value Status Technical Requirement
URL Generated Overlay URL Required Paste your copied URL from Card [07].
Width & Height 420 × 850 (Sidebar) Required Matches your chosen preset resolution.
Control audio via OBS Checked (or Unchecked) Optional Enables routing synthesized audio alerts into the OBS Audio Mixer.
Use custom frame rate 60 FPS Optional Ensures hardware-accelerated 60fps animations.
Custom CSS Keep Default Default Default transparent body background.
Shutdown source when not visible UNCHECKED CRITICAL Must remain unchecked to keep WebSocket connections alive across scenes.
Refresh browser when scene becomes active UNCHECKED CRITICAL Must remain unchecked to prevent resetting chat history on scene transitions.
Page permissions Read access to OBS status Default Allows standard browser runtime environment.
